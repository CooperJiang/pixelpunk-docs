# 项目介绍

PixelPunk 是一个现代化的**全栈式智能图床与资源管理平台**，采用前后端分离架构，集成 AI 图像分析、向量语义搜索、多云存储等前沿技术，为个人和团队提供强大、易用的图片资源管理解决方案。

## 核心特性

### 🤖 AI 智能处理

基于 OpenAI Vision API，提供完整的智能图像处理能力：

- **自动分类** - 智能识别图片类型（风景、人物、动物等）
- **智能打标** - 自动提取关键词和标签
- **语义解析** - 生成图片描述，理解图片内容
- **内容审核** - NSFW 内容检测，保障平台安全
- **自然语言搜索** - 用描述文字搜索图片，支持模糊语义查询

### 🧠 向量搜索引擎

基于 Qdrant 向量数据库，实现语义级搜索能力：

- **以图搜图** - 上传图片找相似内容
- **自然语言搜索** - 用描述文字找图片
- **语义相似度** - 理解图片含义而非简单标签匹配
- **智能推荐** - 推荐关联图片

### ☁️ 多云存储支持

统一存储适配器架构，灵活扩展存储后端：

- **本地存储** - 适合小规模部署
- **S3 兼容存储** - AWS S3、MinIO、Cloudflare R2 等
- **阿里云 OSS** - 国内优选方案
- **腾讯云 COS** - 多云备份
- **七牛云** - CDN 加速
- **又拍云** - 存储优化
- **Backblaze B2** - 低成本存储
- **Google Cloud Storage** - 全球分发
- **Azure Blob Storage** - 企业级存储
- **可扩展架构** - 3 步接入新存储渠道

### 📁 文件管理

完整的文件组织和管理能力：

- **无限层级文件夹** - 支持嵌套目录结构
- **标签与分类系统** - 灵活的内容组织
- **拖拽操作** - 拖拽上传、拖拽移动文件和文件夹
- **右键菜单** - 完整的右键上下文菜单操作
- **批量操作** - 移动、删除、重命名
- **收藏夹** - 快速访问常用资源
- **多种视图** - 网格、列表、瀑布流

### 🔗 灵活分享

强大的内容分享功能：

- **多种分享方式** - 文件夹、单图、混合分享
- **访问控制** - 密码保护、有效期限制
- **相册模式** - 精美的展示页面
- **批量操作** - 批量生成链接
- **打包下载** - 一键下载所有内容
- **邮件通知** - 分享访问提醒

### 🔐 权限与安全

企业级的安全控制机制：

- **防盗链** - 防止图片被盗用
- **IP/域名黑白名单** - 访问控制
- **流量与带宽控制** - 配额管理
- **用户权限管理** - 管理员/普通用户角色
- **操作日志审计** - 完整的审计追踪
- **访问统计分析** - 详细的数据分析

### 🔧 开放 API

完整的 API 接口体系：

- **上传接口** - 支持第三方应用对接
- **随机图片 API** - 绑定文件夹，固定素材
- **权限验证** - Token 认证机制
- **次数控制** - API 调用限制
- **文件类型/尺寸控制** - 灵活的上传策略
- **访问统计** - API 使用分析

### 🎨 主题与国际化

现代化的用户界面：

- **12+ 精选主题** - 赛博朋克、清新、可爱等风格
- **亮暗色自适应** - 跟随系统或自定义
- **动态主题切换** - 无缝切换体验
- **多语言支持** - 中文、英文、日文
- **双维度架构** - 语言 × 主题独立配置
- **双风格文案系统** - 同一语言支持普通和主题风格文案（如赛博朋克风格中文）

## 技术架构

### 技术栈

**前端**
- Vue 3 + TypeScript - 现代化前端框架
- Vite - 极速构建工具
- Pinia - 状态管理
- Tailwind CSS - 原子化 CSS
- VueUse - 组合式工具集

**后端**
- Go 1.23 - 高性能编程语言
- Gin - Web 框架
- GORM - ORM 框架
- JWT - 身份认证
- Viper - 配置管理
- Zap - 结构化日志

**数据存储**
- MySQL / SQLite - 关系型数据库
- Redis - 缓存与会话
- Qdrant - 向量数据库

**AI 服务**
- OpenAI API - 图像分析
- Embedding 模型 - 向量化

**运维部署**
- Docker - 容器化
- Docker Compose - 服务编排
- Nginx / Caddy - 反向代理
- Systemd - 服务管理
